## 动态规划

### 适用范围

主要用于解决 **多阶段决策优化问题**，这类问题可以分为若干个阶段，每个阶段都需要做出决策，而决策又仅依赖于当前的状态。

使用动态规划需要满足 **最优性原理**，即：无论初始状态和决策如何，其余的决策必须相对于初始决策产生的状态构成一个最优决策序列 。简而言之，原问题的最优解包含了其子问题的最优解 。

### 实现思路

1. 证明最优性原理；
2. 设计递推关系式；
3. 迭代实现程序

## 0-1 背包问题

### 问题描述

对于 $n$ 个物品和一个容量为 $M$ 的背包，每个物品 $i$ 有对应的重量 $w_i$ 和效益值 $p_i$ 。要求物品要么整件装入背包，要么不装入（即变量 $x_i$ 只能取 $0$ 或 $1$）。目标是在满足总重量不超过背包容量的约束条件下，极大化总效益。

### 递推关系式

向后处理，设 $f_i(X)$ 表示前 $i$ 个物品在 $X$ 容量下时的最大效益，则：

$$
f_i(X) = \max\left\{ f_{i - 1}(X), f_{i - 1}(X - w_i) + p_i \right\}
$$

其中，当 $X < 0$ 时，$f(X) = -\infty$；当 $X \geq 0$ 时，$f_0(X) = 0$ 

### 最优性证明

假设 $x_1, x_2, \cdots x_n$ 是原问题的最优决策序列，若 $x_1 = 0$，则 $x_2, \cdots, x_n$ 必须是子问题的最优解，否则，如果存在更优的子序列能带来更大的效益，与原序列最优矛盾。

若 $x_1 = 1$，则剩余的决策序列必须是子问题（容量为 $M - w_1$ 的最优解），不然同上，与原序列最优矛盾。

### 序偶对优化

如果直接采用二维数组进行存储，会存储大量无法到达的情况，浪费存储空间，因此，可以考虑使用序偶对进行存储。

使用序偶对 $(P, W)$ 表示背包的一种状态，$W$ 代表当前背包中物品的总重量，$P$ 代表对应的总价值。定义状态集合 $S^i$ 为在考虑了前 $i$ 个物品后，所有有保留价值的最优序偶对的集合；定义衍生集合 $S_1^i$ 为决定装入第 $i$ 个物品后产生的新状态集合。它是由 $S^{i-1}$ 中的每一个序偶对 $(P, W)$ 加上第 $i$ 个物品的价值 $p_i$ 和重量 $w_i$ 得到的，即 $(P + p_i, W + w_i)$ 。

在将 $S^{i-1}$（不装物品 $i$）和 $S_1^i$（装入物品 $i$）合并生成新的 $S^i$ 时，如果存在两个序偶对 $(P_j, W_j)$ 和 $(P_k, W_k)$，满足 **$W_j \ge W_k$ 且 $P_j \le P_k$**，那么 $(P_j, W_j)$ 就会被丢弃。

换句话讲：

> 如果方案 A 比方案 B **“更重且价值还更低（或相等）”**，那方案 A 就是纯粹的劣质方案，以后绝不可能成为最优解的一部分，直接剔除

### 启发性剪枝

虽然序偶对占用空间更小，但是在最坏情况下，时间复杂度仍然会呈现指数爆炸 $O(2^n)$，因此，可以利用贪心等快速方法，求解出一个局部最优解作为全局下界，所有达不到这个下界的序偶对直接去除，进一步降低时间复杂度。

## 矩阵链乘积问题

### 问题描述

给定一个矩阵序列（矩阵链）$A_1, A_2, ..., A_n$，需要计算它们的乘积 $A_1 A_2 ... A_n$ 。因为矩阵乘法满足结合律，不同的加括号方式会导致标量乘法运算的总次数有巨大差异 。目标是寻找最优的括号划分方案，使得矩阵乘积运算的代价（乘法次数）最小。

### 递推关系式

设 $m(i, j)$ 表示计算矩阵链子区间 $A_i A_{i+1} ... A_j$ 的最少代价 。假设最优方案是在矩阵 $A_k$ 之后进行分割（$i \le k < j$），那么总代价等于左半部分代价、右半部分代价，加上这两部分结果矩阵相乘的代价 $p_{i-1}p_kp_j$，即：

$$
m(i,j) = 
\begin{cases}
0, & i = j \\
\min_{i \leq k < j} \left\{ m(i, k) + m(k + 1, j) + p_{i - 1} p_k p_j \right\}, & i < j
\end{cases}
$$

## 最优二分检索树

### 问题描述

给定一个由 $n$ 个标识符组成的集合 $(a_1, a_2, ..., a_n)$，以及对应的成功检索概率 $P(i)$ 和不成功检索概率 $Q(i)$ 。要求构造一棵二分检索树，使得所有检索的平均比较次数（预期成本）达到最小 。预期成本的计算综合了内节点（成功检索）的层级和外节点（失败检索）的层级。

### 递推关系式

设 $C(i, j)$ 表示包含标识符 $a_{i+1}, ..., a_j$ 和外部节点 $E_i, ..., E_j$ 的子树的最小预期成本 。$W(i, j)$ 表示该子树中所有节点的概率权值之和，遍历所有可能的根节点 $a_k$，将其划分为左右子树进行状态转移。

$$
C(i, j) = \min_{i < k \le j}\{C(i, k-1) + C(k, j)\} + W(i, j)
$$

当子树为空时，$C(i, i) = 0$
