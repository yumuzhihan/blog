## 算法是什么

算法是解决一确定类问题的任意一种特殊方法，根据 Knuth 的定义，算法被描述为一组有穷的规则，必须满足五个条件：
- **确定性：** 每一步计算无二义性
- **能行性：** 运算都是基本运算，理论上可以通过纸笔在有限时间内完成
- **输入**： 有 0 个或多个输入
- **输出：** 一个或多个输出，且与输入有特定关联
- **有穷性：** 在执行有穷步运算后可以终止

需要注意的是，由于有的程序并不满足某些特性，比如操作系统在没有任务时会无限空转，并不满足有穷性，所以并**不是所有的程序都是一种算法**。

## 算法分析与渐近表示

### 时间复杂度分类

|  算法类别   |  时间限界   |                        典型时间复杂度递增顺序                        |
| :-----: | :-----: | :-------------------------------------------------------: |
| 多项式时间算法 | 用多项式限界  | $O(1) < O(\log n) < O(n) < O(n \log n) < O(n^2) < O(n^3)$ |
| 指数时间算法  | 用指数函数限界 |                 $O(2^n) < O(n!) < O(n^n)$                 |

### 渐进表示法

- **上界 $O(g(n))$**：如果存在两个正常数 $c$ 和 $n_0$，对于所有的 $n \ge n_0$，有 $|f(n)| [cite_start]\le c|g(n)|$，则记作 $f(n) = O(g(n))$ 。这表示 $f(n)$ 的阶不高于 $g(n)$ 的阶 。
- **下界 $\Omega(g(n))$**：如果存在两个正常数 $c$ 和 $n_0$，对于所有的 $n \ge n_0$，有 $|f(n)| \ge c|g(n)|$，则记作 $f(n) = \Omega(g(n))$ 。这表示 $f(n)$ 的阶不低于 $g(n)$ 的阶 。
- **同阶 $\Theta(g(n))$**：如果存在正常数 $c_1$、$c_2$ 和 $n_0$，对于所有的 $n \ge n_0$，有 $c_1|g(n)| \le |f(n)| \le c_2|g(n)|$，则记作 $f(n) = \Theta(g(n))$ 。这意味着算法在最好和最坏情况下的计算时间/空间在一个常数因子范围内是相同的 。

### 多项式定理

若 $A(n)$ 是一个 $m$ 次多项式，则 $A(n) = O(n^m)$ 。这表明变量 $n$ 的最高阶数为 $m$ 的任一多项式，其计算时间都可以用 $O(n^m)$ 来表示。

## 算法的设计与确认

**问题求解基本步骤：** 理解问题 $\rightarrow$ 选择数据结构和算法设计策略 $\rightarrow$ 设计算法 $\rightarrow$ 证明正确性 $\rightarrow$ 分析算法 $\rightarrow$ 设计程序

**算法表示与确认：**
- **表示方法**：采用结构程序设计的方式
- **确认方法**：目的是确保算法能对所有合法输入给出正确答案，常用方法包括穷举法、推理（数学归纳法、反证法）、构造性证明和测试
